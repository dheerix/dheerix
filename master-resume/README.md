# Master Resume

## Purpose

This repository is the authoritative source for every resume I will create throughout my career.

Unlike a traditional resume, this document is intentionally comprehensive.

Nothing is removed due to page limits.

Instead, targeted resumes are generated by selecting the most relevant experience for a specific opportunity.

This repository contains:

- Complete employment history
- All significant projects
- Leadership contributions
- Technical expertise
- Business impact
- Professional achievements
- Technologies
- Certifications
- Awards
- Speaking and community activities

Every external resume is derived from this repository.

---

## Guiding Principles

- Capture everything once.
- Never lose experience because of page limits.
- Optimize for accuracy before brevity.
- Keep business outcomes alongside technical work.
- Update continuously.
