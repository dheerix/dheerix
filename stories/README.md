# Engineering Story Library

Reusable, source-of-truth story documents that can be rendered into LinkedIn posts, portfolio pages, interview answers, promotion packets, cover letters, and resume bullets.

## Structure

- `01_OPENLANE/GUARDLANE.md`
- `01_OPENLANE/AI_UPLOAD.md`
- `01_OPENLANE/VEHICLE_DETAIL.md`
- `01_OPENLANE/MARKETPLACE_MODERNIZATION.md`
- `01_OPENLANE/AWS_SDK_MIGRATION.md`
- `01_OPENLANE/PROD_INCIDENTS.md`
- `02_HOLLAND_BARRETT/ENTERPRISE_SEARCH.md`
- `03_FOODMESH/SUSTAINABILITY_PLATFORM.md`
- `04_RHEUMERA/HEALTHCARE_PLATFORM.md`
- `05_GENERAL/OWNERSHIP.md`
- `05_GENERAL/TECHNICAL_LEADERSHIP.md`
- `05_GENERAL/FAILURE.md`
- `05_GENERAL/MENTORING.md`
- `05_GENERAL/ARCHITECTURE.md`

## Story Format

Each story should capture:

- Overview
- Business Problem
- My Role
- Current State
- Architecture
- Production Readiness or Technical Challenges
- Decisions and Trade-offs
- Delivery Approach
- Cross-Functional Collaboration
- Leadership
- Business Impact
- Lessons Learned
- Interview Talking Points
- Portfolio Summary
- Resume Bullet
- LinkedIn Version
